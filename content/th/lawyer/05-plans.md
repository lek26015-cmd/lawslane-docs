## เปรียบเทียบแพลน

| | ฟรี | Pro | บริษัท |
| --- | --- | --- | --- |
| แสดงในหน้าค้นหาทนาย | ✓ | ✓ | ✓ |
| แชทกับลูกความไม่จำกัด | ✓ | ✓ | ✓ |
| ป้าย **ทนายแนะนำ** และวงรูปสีทองบนการ์ดทนาย | — | ✓ | ✓ |
| แสดงก่อนทนายแพลนฟรี | — | ✓ | ✓ |
| การ์ดขอบสีทอง แสดงก่อนทนายทุกคนในหน้าแรกและหน้าค้นหา | — | — | ✓ |
| เสนอราคาเปิดคดี จัดการคดี และใบแจ้งหนี้ | — | ✓ | ✓ |
| ผู้ช่วย AI งานคดี (ค้นมาตรา/ฎีกา ร่างเอกสาร ตรวจสัญญา) | — | ✓ | ✓ |
| เครดิต AI ต่อเดือน | 0 | 300 | 1,000 |
| หน้าเว็บส่วนตัว lawslane.com/p/… | — | ✓ | ✓ |

รูปโปรไฟล์ของคุณที่เมนูมุมขวาบน หน้าจัดการบัญชี และแดชบอร์ด จะมีวงสีและป้ายบอกแพลน: Pro เป็นวงสีทองพร้อมป้าย **Pro** ส่วนบริษัทเป็นวงไล่สีทองเข้มถึงส้มพร้อมป้ายพื้นดำ **บริษัท** แพลนฟรีไม่มีวงและป้าย

ดูราคาล่าสุดได้ที่หน้า **แพลนสมาชิก** ในแดชบอร์ด

> ถ้าแพลนหมดอายุหรือยกเลิก ข้อมูลคดีและใบแจ้งหนี้ที่เคยสร้างไว้จะถูกซ่อน (ไม่ถูกลบ) และกลับมาแสดงเมื่อต่อแพลน ส่วนการปิดเคสที่ลูกความจ้างผ่านแชทยังทำได้ตามปกติ

ดูแพลนปัจจุบันได้จากป้ายแพลนด้านบนของเมนูแดชบอร์ด ถ้าได้รับแพลนจากทีม Lawslane (เช่น ช่วงทดลองใช้) ป้ายจะแสดงว่า **ได้รับจากทีม Lawslane** และหน้าแพลนสมาชิกจะบอกวันหมดอายุ

## สมัครแพลน

1. ไปที่ **แพลนสมาชิก** แล้วเลือกแพลน
2. ติ๊กยอมรับข้อกำหนด แพลนนี้**ต่ออายุอัตโนมัติ**ทุกรอบบิล
3. กด **สมัครแพลนนี้** แล้วชำระด้วยบัตรผ่าน Stripe

## เปลี่ยนบัตรหรือยกเลิก

กด **จัดการการชำระเงิน** ในหน้าแพลนสมาชิก จะเปิดหน้าของ Stripe ที่เปลี่ยนบัตร ดูใบเสร็จ หรือยกเลิกการต่ออายุได้ ถ้ายกเลิก จะใช้สิทธิ์แพลนเดิมได้จนจบรอบบิลที่จ่ายไปแล้ว
