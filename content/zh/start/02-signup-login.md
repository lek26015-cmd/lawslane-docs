## 注册

1. 点击网站右上角的 **注册**（สมัครสมาชิก）
2. 选择 **使用 Google 注册**（สมัครสมาชิกด้วย Google），或填写姓名、邮箱和密码
3. 勾选同意 **隐私政策** 和 **服务条款**
4. 通过人机验证后，点击 **注册**（สมัครสมาชิก）

> 如果您是**律师**，请改从 **律师专区** 页面注册，因为需要提交身份验证文件。详见[在 Lawslane 注册成为律师](/lawyer/register)

## 登录

| 方式 | lawslane.com | Cap & Deal | Wittaya |
| --- | --- | --- | --- |
| Google | ✓ | ✓ | ✓ |
| LINE | ✓ | ✓ | — |
| 邮箱 + 密码 | ✓ | ✓ | ✓ |

首次使用 Google 或 LINE 登录时，系统会自动创建账户，并视为您已同意服务条款和隐私政策。

律师请在 lawslane.com 登录页点击 **律师**（ทนายความ）标签。该标签会转到律师登录页，只能使用注册时的邮箱和密码登录（没有 Google 或 LINE 按钮）。

## 忘记密码

1. 在登录页点击 **忘记密码？**
2. 输入邮箱，然后点击 **发送重设链接**
3. 打开邮件并点击链接，然后设置新密码

如果没有收到邮件，请查看垃圾邮件或 Promotions 文件夹。
