## 方案对比

| | 免费 | Pro | 企业 |
| --- | --- | --- | --- |
| 显示在寻找律师页面 | ✓ | ✓ | ✓ |
| 与客户无限聊天 | ✓ | ✓ | ✓ |
| **推荐律师** 标签和金色头像框 | — | ✓ | ✓ |
| 排在免费方案律师之前 | — | ✓ | ✓ |
| 在首页和搜索页最顶部显示大尺寸金色卡片 | — | — | ✓ |

最新价格请查看仪表板中的 **会员方案** 页面。

## 订阅方案

1. 进入 **会员方案** 并选择方案
2. 勾选同意条款。该方案在每个计费周期**自动续订**
3. 点击 **订阅此方案**（สมัครแพลนนี้），然后通过 Stripe 使用银行卡付款

## 更换银行卡或取消

在会员方案页面点击 **管理付款**（จัดการการชำระเงิน），会打开 Stripe 页面，可在其中更换银行卡、查看收据或取消续订。取消后，您仍可使用原方案权益，直至已付费的计费周期结束。
