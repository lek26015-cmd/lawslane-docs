## 方案对比

| | 免费 | Pro | 企业 |
| --- | --- | --- | --- |
| 显示在寻找律师页面 | ✓ | ✓ | ✓ |
| 与客户无限聊天 | ✓ | ✓ | ✓ |
| **推荐律师** 标签，律师卡片上的头像带金色圆环 | — | ✓ | ✓ |
| 排在免费方案律师之前 | — | ✓ | ✓ |
| 金色边框卡片，在首页和搜索页排在所有律师之前 | — | — | ✓ |
| 立案报价、案件管理与账单 | — | ✓ | ✓ |
| AI 案件助手（法条/判例检索、起草文书、合同审查） | — | ✓ | ✓ |
| 每月 AI 积分 | 0 | 300 | 1,000 |
| 个人网页 lawslane.com/p/… | — | ✓ | ✓ |

您在右上角菜单、管理账户页面和仪表板中的头像会带有彩色圆环和方案标签：Pro 为金色圆环加 **Pro** 标签；企业方案为深金到橙色的渐变圆环加黑底 **บริษัท**（企业）标签。免费方案没有圆环和标签。

最新价格请查看仪表板中的 **会员方案** 页面。

> 方案到期或取消后，您建立的案件和账单会被隐藏（不会删除），续订后恢复显示。客户通过聊天委托的案件仍可正常结案。

当前方案显示在控制台菜单顶部的方案标签中。如果是 Lawslane 团队赠予的方案（例如试用），标签会显示 **ได้รับจากทีม Lawslane**（由 Lawslane 团队赠予），会员方案页面会显示到期日期。

## 订阅方案

1. 进入 **会员方案** 并选择方案
2. 勾选同意条款。该方案在每个计费周期**自动续订**
3. 点击 **订阅此方案**（สมัครแพลนนี้），然后通过 Stripe 使用银行卡付款

## 更换银行卡或取消

在会员方案页面点击 **管理付款**（จัดการการชำระเงิน），会打开 Stripe 页面，可在其中更换银行卡、查看收据或取消续订。取消后，您仍可使用原方案权益，直至已付费的计费周期结束。
