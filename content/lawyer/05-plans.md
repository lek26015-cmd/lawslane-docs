## เปรียบเทียบแพลน

| | ฟรี | Pro | บริษัท |
| --- | --- | --- | --- |
| แสดงในหน้าค้นหาทนาย | ✓ | ✓ | ✓ |
| แชทกับลูกความไม่จำกัด | ✓ | ✓ | ✓ |
| ป้าย **ทนายแนะนำ** และกรอบรูปสีทอง | — | ✓ | ✓ |
| แสดงก่อนทนายแพลนฟรี | — | ✓ | ✓ |
| การ์ดสีทองขนาดใหญ่ด้านบนสุดของหน้าแรกและหน้าค้นหา | — | — | ✓ |

ดูราคาล่าสุดได้ที่หน้า **แพลนสมาชิก** ในแดชบอร์ด

## สมัครแพลน

1. ไปที่ **แพลนสมาชิก** แล้วเลือกแพลน
2. ติ๊กยอมรับข้อกำหนด แพลนนี้**ต่ออายุอัตโนมัติ**ทุกรอบบิล
3. กด **สมัครแพลนนี้** แล้วชำระด้วยบัตรผ่าน Stripe

## เปลี่ยนบัตรหรือยกเลิก

กด **จัดการการชำระเงิน** ในหน้าแพลนสมาชิก จะเปิดหน้าของ Stripe ที่เปลี่ยนบัตร ดูใบเสร็จ หรือยกเลิกการต่ออายุได้ ถ้ายกเลิก จะใช้สิทธิ์แพลนเดิมได้จนจบรอบบิลที่จ่ายไปแล้ว
